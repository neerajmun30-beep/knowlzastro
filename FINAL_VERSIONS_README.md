## 🔧 How It Works Together

### Chat Flow (Non-Blocking)
1. **User clicks floating button** → Chat opens immediately
2. **Chat messages/input shown** → No blocking
3. **Background checks run** → After 500ms (non-blocking)
4. **Login/profile prompts** → Shown as notifications (not blocking chat)
5. **User can chat immediately** → Without login/profile

### Advanced Features (Background)
1. **Visitor tracking** → Runs in background
2. **Login prompts** → Shown as non-blocking notifications
3. **Profile prompts** → Shown as non-blocking notifications
4. **Session management** → Works in background

### Offline Mode
1. **Check connection** → Automatic detection
2. **Use cached data** → If offline
3. **Local calculations** → Fallback to local ephemeris
4. **Auto-redirect** → When connection restored
